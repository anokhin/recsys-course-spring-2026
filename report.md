# Отчёт: Улучшение Botify через онлайн‑ML HybridRecommender

## i. Abstract
В данном эксперименте стандартное ранжирование было заменено на **гибридную онлайн‑ML модель (contextual bandit)**. Модель обучается в режиме реального времени, адаптируя веса различных источников рекомендаций на основе обратной связи от пользователя ($track\_time$). В качестве контрольной группы используется **SasRec‑I2I**. Гипотеза заключалась в том, что динамическое взвешивание кандидатов из разных источников (HSTU и I2I) с использованием механизма **exploration** позволит значительно увеличить среднее время сессии за счёт баланса между персональными интересами и релевантностью текущему треку.

## ii. Детали
Реализованный **HybridRecommender** работает как адаптивный агрегатор кандидатов. Основные этапы работы:
1.  **Генерация кандидатов**: Пул формируется из двух ключевых источников — персонализированных списков **HSTU** и рекомендаций на основе текущего трека (**I2I**).
2.  **Вектор признаков (Features)**: Для каждого кандидата строится вектор признаков, включающий скоры из источников (позиция в выдаче) и константный признак (байес).
3.  **Линейная модель**: Предсказание релевантности строится как скалярное произведение вектора признаков и весов пользователя, хранящихся в Redis.
4.  **Exploration**: Реализована **$\epsilon$-greedy стратегия** (с параметром $\epsilon=0.1$), позволяющая системе открывать для пользователя новые треки и избегать зацикливания.
5.  **Онлайн-обучение (SGD)**: При получении времени прослушивания предыдущего трека модель обновляет веса пользователя в Redis по правилу градиентного спуска, минимизируя ошибку предсказания.

### Процесс:
`history (redis)` → `candidates (HSTU + I2I)` → `linear scoring (weights from redis)` → `epsilon-greedy selection` → `SGD update on feedback`.

## iii. Результаты A/B эксперимента
Эксперимент проводился по схеме: **Control = SasRec‑I2I** (`Treatment.C`), **Treatment = HybridRecommender** (`Treatment.T1`). Симуляция была запущена на **30 000 эпизодов**. Скрипт `analyze_ab.py` подтвердил высокую статистическую значимость улучшений. Главным достижением стал рост среднего времени прослушивания на сессию на **72.2%**.

| T1 | **mean_time_per_session** | **72.20** | 68.87 | 75.53 | 2.2627 | 3.8964 | **True** |

**Вывод:** Внедрение гибридной модели с онлайн-обучением весов позволило значительно повысить вовлеченность пользователей. Несмотря на небольшой рост задержки (3.01%), вызванный дополнительными вычислениями и запросами к Redis, качество рекомендаций выросло критически.
