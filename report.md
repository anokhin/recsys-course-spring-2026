## Homework 2 Report

### Abstract

Предложен гибридный рекомендер **HSTU-Reranked**, объединяющий два ML-сигнала: персонализированные кандидаты от HSTU (пользовательский уровень) и контекстуальное ранжирование от SasRec-I2I (сессионный уровень). В контрольной группе — базовый SasRec-I2I, в тритменте — новый рекомендер.

### Детали

**Кандидатная генерация (HSTU):** Для каждого пользователя HSTU предварительно вычислил список из ~100 персонализированных треков, отражающих долгосрочные предпочтения. В отличие от исходной реализации `Indexed`, список не перемешивается — HSTU-ранжирование сохраняется.

**Контекстуальное перераспределение (SasRec-I2I):** Для последнего прослушанного трека берутся SasRec-I2I рекомендации (10 треков). Каждый HSTU-кандидат получает балл: `(sasrec_score, hstu_rank)`, где `sasrec_score > 0` если трек попал в SasRec-I2I выдачу. Трек, одновременно персонализированный (HSTU) и контекстуально релевантный (SasRec-I2I), получает приоритет.

**Фильтрация:** Из истории Redis-а вычитаются уже прослушанные треки (нет повторов).

```
Пользователь → HSTU-кандидаты (100 треков)
                      ↓ фильтр seen_tracks
prev_track → SasRec-I2I рекомендации (10 треков)
                      ↓ scoring: (sasrec_score, hstu_rank)
                  лучший трек
```
