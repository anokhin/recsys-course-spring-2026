## Аннотация

В экспериментальной группе был реализован консервативный ансамбль поверх SasRec-I2I. Контрольная группа оставлена без изменений: стандартный SasRec-I2I из репозитория. Экспериментальная группа использует тот же набор кандидатов SasRec, но переупорядочивает их с помощью нескольких заранее рассчитанных сигналов: сглаженной оценки качества трека, графа переходов, векторных представлений Item2vec, обученных на GPU, и сигнала согласованности по исполнителю. Во время работы сервис остаётся лёгким: botify читает заранее рассчитанный item-to-item индекс из Redis и выбирает первый ещё не прослушанный трек.

Финальный результат в формате проверки автогрейдера с `SEED=31312` и `EPISODES=30000`: метрика `mean_time_per_session` улучшилась на 16.24% и 15.56% в двух повторных запусках. Оба эффекта статистически значимы. Разница прироста между запусками составляет 0.68 п.п.

## Описание

Сначала были собраны логи нескольких прогонов симулятора через публичный API botify. Для каждого трека была оценена сглаженная оценка качества:
```text
quality(track) = (sum_listen_time(track) + prior * global_mean) / (count(track) + prior)
```

Затем были построены дополнительные сигналы. Граф переходов оценивает локальные переходы между треками внутри сессии с затуханием по расстоянию. Item2vec обучается на GPU как skip-gram модель по локальным окнам треков внутри пользовательских сессий. Сигнал исполнителя добавляет небольшой бонус кандидатам того же исполнителя.

Итоговый индекс строится консервативно: набор кандидатов не расширяется за пределы исходного списка SasRec-I2I. Для каждого опорного трека все кандидаты SasRec переупорядочиваются по сумме нескольких сигналов: ранга в SasRec, обученной оценки качества, оценки из графа переходов, близости по Item2vec и сигнала исполнителя. Такой подход сохраняет сильную последовательную структуру SasRec, но добавляет независимые обученные сигналы.

Во время работы `EnsembleRecommender` повторяет поведение item-to-item рекомендера: выбирает опорный трек из истории пользователя с весами по времени прослушивания, затем отдаёт первый ещё не прослушанный трек из итогового ансамблевого индекса. Если индекс не содержит подходящих кандидатов, используется резервный переход к исходному SasRec-I2I.
