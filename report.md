## Homework 2 Report

### Abstract

Поверх списка SasRec стоит линейная Ridge-модель со StandardScaler, которая выбирает следующий трек по скору среди еще не прослушанных в сессии. Обучение использует непрерывный таргет: время прослушивания следующего трека и негативы из того же i2i-списка якоря. А также L2 у Ridge и пофичное масштабирование дополнительно сглаживают перекос к сверхпопулярным позициям.

### Детали

Выборка по журналам Botify: целевое значение это время прослушивания следующего трека, негативы это другие треки из того же SasRec-i2i списка якоря, признаки - ранг в списке, лог-популярность, совпадение артиста и жанра с якорем и ранговые индикаторы.

Обучение: StandardScaler + Ridge (alpha=0.5). В сервисе и контроль, и тритмент читают один и тот же SasRec-i2i из Redis, контроль берет первый еще не прослушанный в сессии кандидат из списка по выбранному якорю, тритмент пересчитывает скор для верхних позиций списка и возвращает лучший по Ridge среди неслышанных.

```mermaid
flowchart TD
  A["История сессии в Redis] --> B[Взвешенный случайный выбор якоря по времени прослушивания]
  B --> C[SasRec-I2I: кандидаты по якорю из Redis, верхняя часть списка]
  C --> D[Признаки пары якорь-кандидат и ранг в списке]
  D --> E[Нормализация StandardScaler, как при обучении]
  E --> F[Скор Ridge]
  F --> G[Только кандидаты вне уже прослушанного в сессии]
  G --> H[Argmax по скору, при неудаче другой якорь, затем резерв SasRec-I2I]
```
