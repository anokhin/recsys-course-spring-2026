# Домашнее задание 2: Контекстный Bandit для музыкальных рекомендаций

## Abstract
Предлагается алгоритм LinUCB (Linear Upper Confidence Bound) для улучшения рекомендаций музыкальных треков. В отличие от статического SasRec-I2I, который использует предпосчитанные item-to-item эмбеддинги, контекстный bandit обучается онлайн на основе поведения пользователя. Алгоритм балансирует exploration (исследование новых треков) и exploitation (использование известных предпочтений), что позволяет лучше адаптироваться к предпочтениям пользователя в реальном времени.

## Детали реализации
Модель использует контекстные признаки треков:
- Жанры (мульти-хот кодирование по 18 жанрам + жанр артиста)
- Год выпуска (нормализованный)
- Настроение/mood (one-hot из 5 категорий)
- Популярность артиста (artist_fans нормализованный)

Контекст пользователя строится как взвешенное среднее признаков прослушанных треков с весом = min(listen_time, 2.0). Параметр alpha=1.5 контролирует баланс exploration/exploitation.

Диаграмма архитектуры:
User Request → Load History (Redis) → Build Context → LinUCB (theta, A_inv)
↓ ↓
Update Model ← Reward (listen_time) ← Track Features ← Select Best Track
