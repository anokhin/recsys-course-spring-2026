# Отчет по домашнему заданию №2

## Abstract
Для улучшения метрики `mean_session_time` был разработан **Contextual ML Ensemble Recommender**, который комбинирует сильные стороны двух разных ML-моделей: Item-to-Item (SasRec) и пользовательской последовательной нейросети (HSTU). Идея заключается в динамическом переключении между моделями на основе неявного фидбека пользователя (времени прослушивания трека).

## Детали
Базовый бейзлайн (SasRec-I2I) отлично работает для поддержания текущего "настроения" сессии. Однако, если пользователю не понравился трек (произошел skip), I2I модель продолжает рекомендовать треки из ошибочного контекста, что приводит к завершению сессии.

`Contextual` рекомендер решает эту проблему:
1. Он проверяет параметр `prev_track_time`.
2. Если `prev_track_time >= 0.55`, мы считаем контекст успешным и делегируем предсказание `SasRec`.
3. Если `< 0.55` (скип), мы отказываемся от контекста I2I и запрашиваем предсказания ML-модели `HSTU` для данного пользователя из Redis. Чтобы сессия не "зацикливалась", мы выдаем случайный трек из топ-15 предсказаний HSTU, исключая только что пропущенный трек.

## Результаты A/B эксперимента
Эксперимент показал статистически значимое улучшение основной метрики по сравнению с SasRec-I2I. `mean_time_per_session` значительно выросло за счет спасения сессий после скипов.
