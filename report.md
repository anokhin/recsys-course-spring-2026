# Домашнее задание 2: Recency-Biased Trained I2I Recommender

## Abstract

Базовый рекомендер **SasRec-I2I** использует предвычисленные item-to-item рекомендации на основе модели SASRec. Я предлагаю улучшенный подход: обучить собственную модель item-item косинусной близости на увеличенном наборе данных (собственные логи + логи других участников курса, ~2.2 млн взаимодействий, 10 000 пользователей, 15 001 трек) и применить **recency-biased** стратегию выбора якоря. В отличие от базового случайного выбора якоря с весами по времени прослушивания, recency-biased подход использует экспоненциально затухающие веса (w_i = 2^(-i) для i-го по новизне трека), что позволяет лучше улавливать краткосрочные предпочтения пользователя.

## Детали

Метод состоит из двух этапов:

**Этап 1 — Обучение модели**: На объединённом наборе данных (4 файла из botify_log_2.tar.gz, которымы поделился участник курса + наши собственные логи) строится матрица user-item взаимодействий размером 10 000 × 15 001. Вычисляется косинусная близость между всеми парами треков. Для каждого трека сохраняются top-10 наиболее похожих треков.

**Этап 2 — Recency-biased рекомендация**: При получении запроса:
1. Загружаются последние 10 треков из истории пользователя.
2. Применяется экспоненциальное затухание: w_i = 2^(-i) × listen_time_i.
3. Выбираются 3 трека с наибольшим весом.
4. Для каждого якоря извлекаются рекомендации из обученной I2I модели.
5. Возвращается первый непрослушанный трек.

```
Обучение:              Рекомендация:
┌─────────────────┐    ┌──────────────────────┐
│ Логи курса ×4    │    │  История пользователя │
│ + наши логи      │    └──────────┬───────────┘
│ ~2.2 млн записей │               │ recency weights
│ 10000 × 15001    │               ▼
│ матрица          │    ┌──────────────────────┐
│ Cosine Sim → I2I │    │  Топ-3 якоря (max w) │
│ top-10/item      │    └──────────┬───────────┘
└────────┬────────┘                │
         │ Redis (DB 6)            │ Trained I2I
         ▼                         ▼
  ┌──────────────┐        ┌──────────────────┐
  │ trained_i2i  │        │ Первый невиденный│
  │ .jsonl       │        │ трек → ответ     │
  └──────────────┘        └──────────────────┘
```

A/B эксперимент: 50/50 сплит, контроль = SasRec I2I, тритмент = Recency-Biased Trained I2I.

## Результаты

A/B эксперимент на **30 000 эпизодах**.

| Метрика | Контроль | Тритмент | Эффект | 95% CI | Значимость |
|---|---|---|---|---|---|
| **mean_time_per_session** | 5.39 | 6.33 | **+17.46%** | [+14.11%, +20.82%] | ✅ |
| mean_tracks_per_session | 9.38 | 10.33 | +10.10% | [+7.55%, +12.64%] | ✅ |
| total_time | 8.02 | 9.63 | +20.03% | [+15.77%, +24.29%] | ✅ |
| mean_request_latency | 0.68 | 0.72 | +5.66% | [-30.32%, +41.64%] | ❌ |

**Среднее время сессии** увеличилось на **+17.46%** (p < 0.001) — убедительное статистически значимое улучшение. Количество треков за сессию выросло на 10.10%. Результат достигнут за счёт комбинации двух факторов: (1) использования enlarged dataset (~2.2 млн взаимодействий от нескольких участников курса) для обучения более качественной модели I2I и (2) применения recency-biased стратегии выбора якоря, которая лучше учитывает текущий контекст пользователя.
