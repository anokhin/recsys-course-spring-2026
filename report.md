## Homework 2 Report

### Abstract

Предложен гибридный рекомендер **EnsembleI2I**, объединяющий SasRec-I2I и LightFM-I2I через агрегацию по всей истории прослушиваний пользователя. В отличие от базового SasRec-I2I, который случайно выбирает один якорь, новый рекомендер строит глобальный скоринг кандидатов по всем якорям одновременно.

### Детали

**Два I2I источника:** SasRec (sequential model) и LightFM (matrix factorization) — два разных ML-алгоритма, обученных на одних данных, но захватывающих разные паттерны: последовательные и коллаборативные.

**Агрегация по истории:** Для каждого трека в истории пользователя (до 10 последних) берутся рекомендации обоих моделей. Каждый кандидат получает балл:

```
score[track] += (listen_time / total_time) * (N - rank)
```

где `rank` — позиция трека в списке I2I, `N` — длина списка. Итого суммируем по всем якорям и обеим моделям.

**Почему должно работать лучше:** Базовый I2IRecommender выбирает один случайный якорь — если его топ-кандидаты уже услышаны, он переходит к следующему. Глобальный скоринг позволяет найти трек, который консистентно рекомендуется многими якорями (и SasRec, и LightFM) — такой трек ближе к интересу текущей сессии.

```
История: [(track_1, t1), (track_2, t2), ..., (track_k, tk)]
    ↓ для каждого якоря: SasRec-I2I + LightFM-I2I
scores[candidate] = Σ weight_i * rank_score_i
    ↓ filter seen_tracks
best candidate
```
