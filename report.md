# Домашнее задание 2: Smart I2I Recommender с SVD эмбеддингами

## Abstract
Предлагается улучшенный I2I рекомендер, использующий предобученные SVD-эмбеддинги треков (200 компонент) на 188K пользовательских событиях, собранных через честный симулятор. Ключевое отличие от базового SasRec-I2I — умное взвешивание якорей с учётом времени прослушивания (recency), штрафов за скипнутые треки и механизмов diversity. Рекомендер показал статистически значимое улучшение mean_session_time на +3.9% (p < 0.05).

## Детали реализации

### Сбор данных и обучение
1. Собрано 100K пользовательских сессий через симулятор (188K событий)
2. Построена user-item матрица с TF-IDF взвешиванием: `weight = (1 + ln(tf*3)) * idf`
3. Обучен Truncated SVD (200 компонент, 20 итераций) для получения эмбеддингов треков
4. Сгенерированы I2I рекомендации через cosine similarity (топ-10 для каждого трека)

### Smart I2I Recommender
Алгоритм выбора следующего трека:
1. **История пользователя** делится на "хорошие" (time ≥ 0.7) и "плохие" (time < 0.3) треки
2. **Веса якорей**: комбинация времени прослушивания и давности (recency = позиция в истории)
3. **Скоринг кандидатов**: вес якоря × позиция в рекомендациях + бонус за глобальную популярность − штраф за скипнутые треки − штраф за дубли в сессии
4. **Diversity**: кандидаты собираются от топ-5 якорей для разнообразия

### Диаграмма архитектуры
User Request → Load History (Redis) → Split good/bad tracks
↓ ↓
Select Top-5 Anchors ← Weighted by time×recency
↓
Get I2I candidates from SVD embeddings (Redis)
↓
Score candidates: position + popularity − skips − duplicates
↓
Return best candidate
