## Abstract

В работе предложена content-based рекомендательная модель, основанная на семантическом сходстве треков. Предложенный подход опирается на текстовые характеристики треков (артист, жанры, настроение, описание и т.д.). Основная идея состоит в том, что если пользователю понравился трек, то с высокой вероятностью ему подойдут треки, близкие по содержанию. Для этого каждому треку сопоставляется вектор признаков, после чего рекомендации формируются по косинусному сходству между треками.

---

## Детали

Модель реализована в файле `train_learned_i2i.py`. Сначала из файла `tracks.json` считывается каталог треков, где для каждого трека формируется текстовое представление на основе полей `artist`, `genres`, `mood`, `summary`, `title` и связанных характеристик артиста. Далее используется `TfidfVectorizer` для преобразования текста в числовые признаки, после чего применяется `TruncatedSVD` для снижения размерности и получения компактных эмбеддингов треков.

После нормализации эмбеддингов вычисляется матрица косинусного сходства и для каждого трека выбираются top-K наиболее похожих треков. Результат сохраняется в файл `learned_i2i.jsonl` в формате `item_id -> recommendations`. На стороне сервера реализован класс `LearnedI2IRecommender`, который по `prev_track` получает список кандидатов из Redis и возвращает первый релевантный трек (исключая уже прослушанные пользователем).

## Результаты A/B эксперимента

Предложенная модель была протестирована против baseline (SASRec-I2I). Результаты:

| Метрика                  | Control | Treatment | Effect (%) | Significant |
|--------------------------|--------|-----------|------------|------------|
| time                     | 9.388  | 10.245    | +9.12%     | yes        |
| sessions                 | 1.283  | 1.269     | −1.10%     | no         |
| mean_request_latency     | 0.329  | 0.322     | −2.06%     | yes        |
| mean_tracks_per_session  | 12.389 | 13.022    | +5.11%     | yes        |
| mean_time_per_session    | 7.460  | 8.089     | +8.43%     | yes        |

Основная метрика **mean_time_per_session** увеличилась на **8.43%**, что является статистически значимым улучшением.

## Вывод

Content-based подход показал более стабильные и качественные рекомендации по сравнению с последовательностной моделью. Использование семантического сходства треков позволяет лучше обобщать предпочтения пользователей и увеличивает вовлечённость, что подтверждается результатами A/B тестирования.
