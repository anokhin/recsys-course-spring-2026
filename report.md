## Homework 2 Report

### Approach

Replaced the HSTU-based Treatment T1 with recommendations generated by **iALS** (Implicit Alternating Least Squares) trained on simulation interaction logs.

**Model**: iALS via the `implicit` library
**Features**: user×track interaction matrix weighted by log(1 + total_listened_time)
**Hyperparameters**: factors=64, iterations=20, regularization=0.01
**Output**: top-100 per-user recommendations in HSTU format

### Why iALS

- Directly optimizes on the listening-time signal that the A/B metric measures
- Fast to train (< 5 min on 30k episode logs)
- Per-user personalization vs. SasRec I2I which is item-to-item only
- Ensemble effect: iALS captures global collaborative patterns while SasRec captures local item transitions

### Training pipeline

1. Run simulation for 30 000 episodes to collect interaction logs
2. Aggregate (user, track, total_time) pairs
3. Train iALS on log-scaled time confidence matrix
4. Generate top-100 recs per user → `botify/data/hstu_recommendations.json`
5. Rebuild Docker container and re-run A/B simulation
