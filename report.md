# Homework 2

## Abstract

Цель — превзойти `SasRec-I2I` по метрике `mean_time_per_session` в честном A/B-тесте.
Реализован `MLRanker`: `GradientBoostingClassifier`, обученный на логах bootify, который ранжирует кандидатов из SasRec top-20 и заменяет базовую рекомендацию при высокой уверенности модели. Результат — статистически значимый прирост времени сессии на +16.81%.

## Подробности

### Настройка онлайн-сервиса

Контрольная группа использует `SasRec-I2I` без изменений. В тестовой группе работает `MLRanker`, который при каждом запросе `/next` получает пул кандидатов из SasRec top-20, скорит их с помощью ML-модели и возвращает лучший — но только если уверенность модели достаточно высока. В противном случае происходит используется стандартный `SasRec-I2I`. Трафик генерируется симулятором через HTTP-вызовы к сервису botify. Разбивка пользователей по группам детерминирована (MurmurHash по `user_id` и имени эксперимента `ML_RANKER`).

### Модель и признаки

Модель предсказывает вероятность хорошего прослушивания рекомендации. Признаки вычисляются из доступных данных:

| Признак | Описание |
|---|---|
| `prev_time` | Доля прослушанного предыдущего трека |
| `same_artist` | Совпадает ли артист с предыдущим треком |
| `sasrec_rank` | Позиция кандидата в SasRec-списке для prev\_track |
| `sasrec_rr` | Обратный ранг (1/rank) |
| `sasrec_candidate_count` | Размер SasRec-пула |

Логика замены: рекомендация меняется только если `prev_track_time >= 0.80`, `best_score > 0.78` и `best_score > baseline_score + 0.10`. При любой ошибке сервис откатывается на SasRec-I2I или на первого кандидата из пула.
