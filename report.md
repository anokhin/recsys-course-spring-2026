# HW2: ALS Next-Track Recommender

## Abstract

Предложен рекомендер на основе матричной факторизации ALS, обученный на матрице переходов между треками. Для каждой пары треков (A, B) вес в матрице равен суммарному времени прослушивания трека B сразу после трека A в логах симулятора. ALS находит латентные паттерны этих переходов и генерирует I2I рекомендации. AB-тест показал статистически значимое улучшение метрики mean_time_per_session на +3.32% по сравнению с базовым рекомендером SasRec-I2I.

## Details

Из логов симулятора (~1.6M событий) извлечены последовательные пары треков внутри сессий. Построена разреженная матрица переходов размером 16198 x 16198, где значение ячейки (A, B) равно суммарному времени прослушивания трека B после трека A. На этой матрице обучена модель ALS с 256 латентными факторами, регуляризацией 0.01, за 30 итераций. Рекомендации для трека X генерируются как топ-10 треков по скалярному произведению эмбеддинга X (как prev_track) со всеми эмбеддингами next_track. Итоговые рекомендации подключены через существующий I2IRecommender.
```
[Логи симулятора] → [Матрица переходов 16198×16198] → [ALS модель]
                                                              ↓
[AB-тест vs SasRec] ← [I2IRecommender] ← [I2I рекомендации (топ-10)]
```
## Results

AB-тест проводился на 30000 эпизодов симулятора с seed=31312. Контроль - SasRec-I2I, тритмент - ALS next-track. Мой рекомендер статистически значимо победил контроль по ключевой метрике mean_time_per_session (+3.32%), а также по mean_tracks_per_session (+1.94%) и суммарному времени сессии (+4.10%).
