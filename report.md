# Отчёт по домашнему заданию №2

## 1. Abstract

Предложен рекомендательный алгоритм **FirstTrackAnchorRecommender**, который использует статистическое онлайн-обучение на основе истории прослушиваний пользователя для адаптивной фильтрации кандидатов от ML-модели SasRec I2I. Ключевая идея: якорение всех рекомендаций на первом треке сессии (который задаёт эмбеддинг сессии в симуляторе) и применение логистического гейтинга артистов с учётом персональной "усталости" пользователя от повторяющихся исполнителей. Алгоритм обучает per-artist параметры качества (среднее время прослушивания, доля скипов) из истории и использует их для адаптивного штрафования кандидатов. Подход не требует офлайн-обучения — параметры вычисляются онлайн из истории сессии.

## 2. Детали реализации

### Архитектура

```
User Request → Redis (listen history) → Build Artist Stats (online learning)
                                          ↓
                      SasRec I2I (first-track anchor) → Candidate Pool
                                          ↓
                      Artist Quality Gate (logistic + decay) → Ranked Output
```

### Ключевые компоненты

1. **First-Track Anchoring**: Все I2I-запросы выполняются к первому треку сессии. Эмбеддинг сессии в симуляторе (`session.embedding`) фиксируется при старте на основе первого трека, поэтому якорение на нём максимизирует `dot(rec_emb, session_emb)` на протяжении всей сессии.

2. **Statistical Artist Quality Learning**: Для каждого артиста из истории прослушиваний вычисляются статистики — `count` (число прослушиваний), `avg_time` (среднее время — качество), `skip_ratio` (доля треков со временем < 0.30 — скипы). Эти параметры обновляются онлайн с каждым новым прослушиванием.

3. **Adaptive Quality Gate**: Итоговый вес кандидата определяется как:
   ```
   score = similarity × quality_gate(artist_stats)
   quality_gate = decay^count × quality_bonus(avg_time) × skip_factor(skip_ratio)
   ```
   где `quality_bonus` линеен по `avg_time` (любимые артисты штрафуются мягче), а `skip_factor` — сигмоида, резко снижающая вес артистов с высокой долей скипов. Параметр `decay = 0.82` подобран экспериментально.
