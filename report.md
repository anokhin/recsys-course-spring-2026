## Abstract
В качестве treatment я использую простой персонализированный ML-рекомендер с заранее подготовленными рекомендациями для пользователя. В treatment используется отдельный набор рекомендаций из файла `my_hstu_recommendations.json`, который подаётся через `Indexed`-рекомендер, меняется источник рекомендаций только для T1

## Детали
Сервис поднимается в `botify`, а распределение между контролем и treatment происходит в `server.py` через эксперимент `HSTU` так, что пользователи из группы `C` получают ответы от `SasRec-I2I`, пользователи из группы `T1` — от моего рекомендера. Для treatment загружается отдельный файл с рекомендациями `botify/data/my_hstu_recommendations.json`, после чего `Indexed` возвращает один из заранее рассчитанных треков для конкретного пользователя.

В `config.json` переключён путь на мой файл рекомендаций, а в `server.py` treatment-рекомендер создаётся один раз при старте сервиса и дальше переиспользуется во всех запросах.
