# Отчет по домашнему заданию №2: Музыкальный рекоммендер

### 1. Abstract
Основная идея эксперимента — внедрение гибридной контекстной системы рекомендаций, объединяющей персональные последовательные предсказания модели **HSTU** и механизм **сессионной фильтрации**. В отличие от базового SasRec-I2I, предложенное решение учитывает историю текущей сессии пользователя в реальном времени, предотвращая повторы треков и используя эффект «Sticky Artist» для удержания слушателя, если текущий артист ему интересен.

### 2. Детали реализации
Реализован `ContextualRecommender`, который работает по следующему алгоритму:
1.  **Фильтрация истории:** С помощью Redis List (`listen_history_redis`) извлекаются все треки, прослушанные в текущей сессии. Они исключаются из всех последующих рекомендаций.
2.  **Гибридный выбор:** 
    *   Если пользователь прослушал более 10% текущего трека, система предлагает случайный новый трек того же артиста (используя `artists_redis`).
    *   Если артист «исчерпан» или трек был пропущен, используются персональные рекомендации модели **HSTU** из предвычисленной базы.
    *   В качестве последнего уровня (fallback) используется фильтрованный по истории **SasRec-I2I**.
Такой подход позволяет сочетать точность ML-модели с логикой реального поведения пользователя в сессии.

### 3. Результаты A/B эксперимента
Эксперимент проводился во встроенном симуляторе Botify. Группа контроля (C) получала стандартный `SasRec-I2I`, группа тритмента (T1) — `ContextualRecommender`.
