# Отчёт по Домашнему заданию 2 Чернов Даниил

## Аннотация

Предлагается рекомендер на основе **LightFM I2I** с двумя улучшениями, учитывающими контекст текущей сессии.
LightFM — модель коллаборативной фильтрации, которая обучается на истории взаимодействий и строит латентные представления треков
Улчшения:
- Детерминированный выбор якорного трека с максимальным суммарным временем прослушивания вместо случайного взвешенного семплирования.
- Фильтрация кандидатов, чей артист уже встречался в текущей сессии — это напрямую снижает штраф `artist_discount_gamma` функции награды симулятора.

## Детали

Рекомендер загружает историю прослушиваний пользователя и строит два множества: треки, уже сыгранные в сессии (`seen`), и артистов этих треков (`recent_artists`). Из истории выбирается якорный трек — тот, у которого наибольшее суммарное время прослушивания. По этому треку из Redis достаются LightFM I2I-соседи.

Сначала среди соседей ищется трек, которого нет в `seen` и чей артист не входит в `recent_artists` — это основная рекомендация по артисту. Если такого трека не нашлось, ограничение по артисту снимается и возвращается просто первый непрослушанный трек. Если и это не сработало используется случайный рекомендер.

Реализация: `botify/botify/recommenders/lightfm_contextual.py`.
