# Homework 2 Report

## Abstract

Идея: заменить SasRec-I2I рекомендер на item-to-item рекомендер, основанный на LLM-эмбеддингах треков.
SasRec-I2I строит рекомендации по обученным весам последовательной модели.
Embedding-I2I использует семантическое сходство треков в пространстве эмбеддингов языковой модели (llama3.1),
которое напрямую соответствует метрике симулятора: `score = dot(rec_embedding, session_embedding)`.
В качестве метрики успеха — стат. значимый рост `mean_time_per_session` относительно SasRec-I2I в контроле.

## Details

SasRec-I2I оптимизирует задачу предсказания следующего трека по последовательности прослушиваний.
Однако метрика симулятора — это dot product между эмбеддингом рекомендованного трека и
эмбеддингом интереса сессии. Если использовать те же эмбеддинги для построения I2I-рекомендаций
(top-100 ближайших соседей по косинусному сходству), то рекомендер будет напрямую оптимизировать
ту же метрику, по которой оценивается сессия.

Схема работы:

```
[треки из истории прослушиваний пользователя]
            │
            ▼
  time-weighted выбор anchor-трека
            │
            ▼
 ┌────────────────────────────────┐
 │  Embedding-I2I (оффлайн, Redis)│
 │  top-100 ближайших по cosine   │
 │  от llama3.1 embeddings        │
 └────────────────────────────────┘
            │
            ▼
  фильтрация уже услышанных треков
            │
            ▼
      top-1 непрослушанный трек
```

Предрасчёт (`script/make_embedding_i2i.py`, запускается в `make setup`):
1. Загружает `sim/data/embeddings.npy` (16198 треков × 4096 dim, llama3.1)
2. L2-нормализует все эмбеддинги
3. Батчевым матричным умножением вычисляет top-100 ближайших соседей для каждого трека
4. Сохраняет результат в `botify/data/embedding_i2i.jsonl` (формат идентичен sasrec_i2i.jsonl)

Реализация:
- `HSTURecommender` (файл `botify/botify/recommenders/hstu.py`) — создан как baseline HSTU-рекомендер
- В эксперименте T1 используется `I2IRecommender` с embedding-I2I данными в Redis DB5
- Fallback при недоступности эмбеддингов: используется sasrec_i2i.jsonl

A/B тест: эксперимент `HSTU`, сплит 50/50:

| Группа | Рекомендер |
|--------|-----------|
| C      | SasRec-I2I (контроль) |
| T1     | I2IRecommender с Embedding-I2I |
